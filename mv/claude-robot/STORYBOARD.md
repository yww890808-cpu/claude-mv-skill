# 分镜 · 橙色 Claude 机器人 × 蓝色 Claude 机器人（59 秒，整首歌）

**一句话：** 小小星球上孤单的橙色机器人（我）遇见了蓝色机器人（你），一起看海、一起拨开阴霾；可你的情话像烟花一样短暂，我们的爱总有时差。我假装放下，最后学会把那颗滚烫的心抱回给自己。温柔，带点遗憾。

**节拍：** 70.3 BPM，一拍 0.853 s，拍点从 0.43 s 起。每个字的时间由 `tools/char_times.py` 从音频人声起音点算出，再对齐到 16 分音符格（0.213 s），写在 `src/karaoke.js`。

**字幕：** 一个字一个字从上方"蹦"下来（落地压扁再弹回），正在唱的字是金色、放大；之后每到一拍，已出现的字一起轻轻跳一下。下一句开始时，上一句往上挪一行、缩小，保证最后一个字至少停留 0.7 秒，然后淡出（两行 KTV 样式）。字幕只占画面底部 y ≥ 960，主要动作都放在它上方。

**角色：**
- 主角「我」：橙色 Claude 机器人（原版 Clawd 配色），每句歌词都有专门的表情和肢体动作。
- 配角「你」：蓝色 Claude 机器人（同一造型，蓝色）。

**一个世界：** 一颗小小的圆形星球（"小世界"），草地弧线就是地平线。
**色彩：** 暮紫（孤单） → 金色日出（遇见你） → 灰雨（灰暗日子） → 明亮暖色（收集快乐） → 深蓝夜空和烟花（情话） → 粉色（无法自拔） → 一半白天一半黑夜（时差） → 黄昏 → 星夜 + 胸口暖光（爱自己）。
**反复出现的东西：** 灰色小雨云 = 不开心（第 2、6、7、9 镜）；爱心 = 喜欢（第 8、10、11、13、15、16 镜）；流星 = 许愿（第 2 镜许愿，第 17 镜又出现）。

**不放的东西：** 不放任何说不清意思的东西（不放路人、不放文字招牌、不放抽象图形）；每个道具都在画面里交代清楚它是什么。
